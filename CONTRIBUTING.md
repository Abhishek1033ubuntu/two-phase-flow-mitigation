# Contributing Guidelines

Thank you for reviewing the **Two-Phase Flow & Lubricant Contamination Mitigation** project.

## How to Contribute
1. **Report Issues:** Open an issue regarding modeling parameters, fluid mechanics formulations, or edge cases.
2. **Submit Enhancements:** Fork the repository, create a feature branch, and submit a Pull Request with updated calculations or scripts.
3. **Simulation Verification:** If adding new simulation scripts, ensure code is documented and executable in Google Colab / standard Jupyter environments.
